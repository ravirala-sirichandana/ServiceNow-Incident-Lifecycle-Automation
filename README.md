# Incident Lifecycle Automation in ServiceNow

--Project Overview

Incident Lifecycle Automation in ServiceNow is a capstone project that demonstrates how IT incidents can be managed from creation to resolution. The project uses a ServiceNow Personal Developer Instance (PDI) to demonstrate incident classification, assignment, knowledge integration, child incident management, and SLA tracking.

-- Objectives

- Create and classify incidents with appropriate details.
- Assign incidents to the relevant support group.
- Integrate Knowledge Articles to support incident resolution.
- Create and manage child incidents.
- Record probable causes and resolution details.
- Verify incident status and SLA records.

-- Tools and Technologies

- ServiceNow Personal Developer Instance (PDI)
- Incident Management
- Knowledge Management
- Configuration Item (CI) Management
- Task SLA Tracking

-- Features Implemented

1. Incident Creation and Classification: Created a VPN connectivity incident and documented the authentication error.
2. Incident Assignment: Assigned the incident to the Network support group.
3. Knowledge Integration: Attached relevant Knowledge Articles and marked an article as helpful.
4. Child Incident Management: Created a child incident to track a related issue.
5. Cause and Resolution Documentation: Recorded the probable cause, resolution code, and resolution notes.
6. Knowledge Article Creation: Created a Knowledge Article from the resolved incident.
7. SLA Monitoring: Reviewed related Task SLA records and checked their breach status.
8. Incident Resolution: Verified the parent and child incident resolution details.

-- Project Workflow

Incident Creation → Classification → Assignment → Knowledge Integration → Child Incident Management → Resolution → SLA Verification

-- Repository Contents

This repository contains a ZIP archive with the documentation for all six project phases, including the available subfolders and supporting project files.

-- Project Outcome

The project demonstrates key ServiceNow incident management capabilities, including organized incident handling, knowledge reuse, child incident tracking, resolution documentation, and SLA monitoring.
